# ImageFeed

ImageFeed is an iOS training project for Yandex Practicum.

## Sprint 9

Implemented:
- Launch Screen
- image feed with 20 local images
- dynamic cell height based on image proportions
- rounded image corners
- current date and gradient overlay
- like icons for even-indexed cells
- profile screen (`ProfileViewController`)
- profile avatar, name, username, bio and logout button
- full-screen image screen (`SingleImageViewController`)
- `UIScrollView` with zoom support
- back button
- share button and system share sheet
- iPhone only
- portrait orientation
- minimum iOS version 17.0

## Technologies

Swift, UIKit, Storyboard, Auto Layout, UITableView, UIScrollView, UIActivityViewController.
